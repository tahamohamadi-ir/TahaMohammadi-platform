# راهنمای ساده promotion تصاویر (برای مالک)

## خلاصه یک خطی

شما **منابع تصویری** را قبلاً تأیید کرده‌اید (۲۰۲۶-۰۸-۲۹). «Promotion» یعنی تبدیل آن فایل‌های طراحی به **فایل‌های runtime** با اندازه، فرمت، alt و جایگاه مشخص — نه تأیید دوبارهٔ حق مالکیت.

## شما چه کاری باید بکنید؟

### گروه A — تصاویر تزئینی/محیطی (نیاز به تأیید سنگین ندارید)

این‌ها فقط atmosphere هستند، نه محتوای واقعی پروژه:

| تصویر | جایگاه پیشنهادی | کاری که از شما لازم است |
|---|---|---|
| `portal-centered-dark/light` | Language gateway | **هیچ** — decorative؛ alt خالی |
| `portal-orbit-dark/light` | Home hero background | **هیچ** — decorative |
| `brand-primary`, `brand-favicon` | Header / favicon | فقط بگویید «باشد» یا اگر SVG جایگزین می‌خواهید بگویید |

برای این گروه، تیم/agent derivative فنی (WebP/AVIF، crop موبایل) را انجام می‌دهد.

### گروه B — تصاویر preview (نیاز به یک تصمیم کوتاه)

| تصویر | سؤال از شما |
|---|---|
| `project-dashboard-systems` | به کدام پروژه وصل شود؟ پیشنهاد: `project.dashboard-research` |
| `project-data-architecture` | پیشنهاد: `project.pars-sql` |
| `project-visual-communication-network` | پیشنهاد: `project.pars-sql` یا research |
| `blog-coral-stairs` | پیشنهاد: بخش Writing (عمومی، بدون رکورد خاص) |
| `learning-sage-library` | پیشنهاد: Teaching — یا تا آماده شدن teaching، unavailable |
| `gallery-ivory-forms` | پیشنهاد: Creative — یا unavailable تا portfolio آماده شود |
| `project-placeholder-ivory-stairs` | **فقط** placeholder «کار آینده» — هرگز به‌جای پروژه واقعی |

پاسخ شما می‌تواند به‌صورت یک جمله در چت باشد، مثلاً:  
«تصویر dashboard به پروژه organizational dashboards وصل شود؛ بقیه decorative یا unavailable.»

### گروه C — چیزهایی که نباید publish شوند بدون مدارک

- اسکرین‌شات یا نمودار کارفرما (مثلاً behavioral platform)
- هر تصویری که credit/rights روشن نیست
- عکس‌هایی که به publication واقعی وصل نیستند

## فرآیند سه مرحله‌ای (برای شما)

```text
1. منابع در Front-End/Assets تأیید شده‌اند          ← انجام شده
2. شما فقط mapping گروه B را تأیید می‌کنید         ← یک پیام کوتاه کافی است
3. agent derivative فنی + QA را در ledger ثبت می‌کند ← بدون کار اضافه از شما
```

## اگر نمی‌خواهید الان تصمیم بگیرید

هیچ مشکلی نیست. سایت با **honest unavailable state** یا تصاویر decorative-only بالا می‌آید؛ بعداً promotion را تکمیل می‌کنیم.

## سند فنی کامل

جزئیات فنی در `ASSET-PROMOTION-LEDGER.md` و checklist هفت‌مرحله‌ای همان‌جا است.
