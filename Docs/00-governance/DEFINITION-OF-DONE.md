# Definition of Done

A task is done when all applicable statements are true:

- The requested behavior exists.
- Automated tests cover the changed behavior.
- Required manual checks have evidence.
- API and content contracts remain consistent.
- Accessibility and security requirements pass.
- Documentation matches current behavior.
- No secret or generated output is staged.
- Git status contains no unexplained change.
- Deferred work has an explicit register entry.
- Release status names only the gate actually passed.
