# Change Process

1. Select one task from the master task list.
2. Confirm the owning repository.
3. Read affected contracts.
4. Inspect current Git status.
5. Write the test that proves the requested behavior.
6. Implement one complete slice.
7. Run the repository verification commands.
8. Update affected documents and registers.
9. Commit an exact file manifest.
10. Open a pull request with evidence.

Cross-repository changes require one coordination task and one local task per repository.
