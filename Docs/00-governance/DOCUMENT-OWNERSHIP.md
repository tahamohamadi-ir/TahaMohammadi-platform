# Document Ownership

| Subject | Canonical owner |
|---|---|
| Workspace architecture | `Docs/02-architecture/SYSTEM-ARCHITECTURE.md` |
| API boundary | `Docs/03-contracts/API-CONTRACT.md` |
| Authentication | `Docs/03-contracts/AUTH-CONTRACT.md` |
| Design intent | `Docs/04-design/DESIGN-AUTHORITY.md` |

| Backend implementation | `Back-End/docs/` |
| Public implementation | `Front-End/public-site/docs/` |
| Admin implementation | `Front-End/admin-panel/docs/` |

An implementation document may refine its scope. It cannot redefine another repository's interface.
