# Product Scope

## Included

- Persian RTL and English LTR public routes
- Public profile, research/topics/statements, projects, articles, publications, courses/lessons, creative works, books, talks, resources, collections, series, CV, contact and search
- Independent localized detail pages for every publishable work
- Admin editing of story blocks, translations, evidence/relations, navigation, SEO, bounded scene presets and aggregate analytics
- Authenticated admin content management
- Draft, review, preview, schedule, publish, archive, and revision workflows
- Media, timeline, home composition, and research graph management
- Static-first public delivery backed by published-only APIs

## Excluded from the first release

- E-commerce
- Public user accounts
- Community comments
- Course enrollment and an active newsletter in V1
- Unbounded generative content
- WebGL as a content dependency
- A React single-page shell for public content
