# Seed v1 — Supplemental Content and Safe Empty States

This supplement is for **initial site seeding**, not final production copy.

It fills the structural holes that should have content records for development purposes without inventing facts.

## Added public-safe seed states

- Creative work: bilingual empty-state copy until media, authorship, credits, and rights are confirmed.
- Teaching: bilingual admin-safe empty state; module should remain hidden by default.
- CV: bilingual unavailable/download-pending state until an owner-approved public CV exists.

## Added admin-only records

- M.A./B.A. diploma and transcript verification
- Thesis-title/GPA/date verification
- Stanford Medicine credential verification
- Behavioral-platform IP clearance
- Dashboard publication/media rights
- Legal/privacy implementation dependency
- Writing/publication metadata checklists
- Seed privacy/publication defaults

## Default decisions used for development

- Email: public
- Phone: private
- Public city/country: omitted
- ORCID: shown on research/profile surfaces, not primary contact CTA
- PhD/research availability for 2027: available as draft content
- Public CV/resume download: disabled until owner-approved files exist
- Locale fallback: none
- Media: withheld until rights are confirmed

## Important

These records are seed data. They are intentionally reversible and should not be interpreted as final owner approval.
