# Non-Goals

<!-- PRODUCT-V2.1 -->
V1 additionally excludes course enrollment and an active newsletter. Three.js/GSAP are selected visual enhancements, while all core content remains HTML. These non-goals do not block independently publishable books/talks/resources/collections/series/lessons or broad admin editing authorized by ADR-0010.
<!-- /PRODUCT-V2.1 -->

The rebuild is not a visual reskin of the legacy frontend.
The rebuild does not preserve legacy CSS, templates, or frontend component structure.
The rebuild does not merge the three repositories.
The rebuild does not infer missing content from old screenshots.
The rebuild does not make optional motion or 3D required for comprehension.
