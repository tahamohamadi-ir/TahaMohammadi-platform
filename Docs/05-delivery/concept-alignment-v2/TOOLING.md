## اتصال و آزمون

MCP با نام `headroom` در تنظیمات کاربر Codex ثبت شد. مسیر اجرایی: `C:/Users/Taha/.local/bin/headroom.exe` با آرگومان `mcp serve`. telemetry خاموش و output shaper صفر است. نسخهٔ پشتیبان تنظیمات پیش از تغییر، خارج مخزن در `%LOCALAPPDATA%/headroom/setup-backups/` نگهداری شد؛ محتویات تنظیمات وارد گزارش نشده است.

آزمون واقعی stdio MCP: initialize و list_tools موفق؛ سه ابزار compress/retrieve/stats موجود. نمونهٔ JSON ساختگی ۱۲۰ رکوردی از **۳۱۲۸ به ۱۲۲۰ توکن** رسید؛ اصل متن از hash عیناً بازیابی شد. هیچ درخواست پولی به مدل برای این آزمون ارسال نشد.

این آزمون کاهش حدود ۶۱٪ همان نمونه را نشان می‌دهد؛ کیفیت پاسخ مدل، صرفه‌جویی کل کار و سهمیهٔ Codex اندازه‌گیری نشده‌اند. بازیابی اصل، فشرده‌سازی را به تضمین حفظ استدلال تبدیل نمی‌کند.

MCP نصب‌شده هنگام بارگذاری مجدد اتصال‌ها در دسترس قرار می‌گیرد؛ ابزارهای همین گفت‌وگوی باز لزوماً تازه نمی‌شوند. MCP به‌تنهایی همهٔ ترافیک Codex Desktop را عبور نمی‌دهد. proxy با حالت lossless به‌طور موقت اجرا و سپس متوقف شد؛ سرویس دائمی یا تغییر مسیر حساب فعلی برقرار نشده است.

## استفادهٔ کم‌ریسک در کار روزمره

1. با نام فایل/نماد و خروجی کوتاه جست‌وجو کن.
2. فقط بخش مربوط به تغییر و قرارداد رابط را کامل بخوان.
3. برای خروجی تکراری بزرگ از compress استفاده کن؛ برای تصمیم دقیق اصل را retrieve کن.
4. حقیقت شخصی، الزامات، خطای آزمون و دادهٔ حساس را از خلاصه حدس نزن.
5. دستورهای بررسی کد: `headroom sg`، `headroom diff` و `headroom loc`؛ گزینه‌ها از help همان دستور.

برای اجرای آگاهانهٔ Codex CLI از طریق proxy، فرمان پشتیبانی‌شده `headroom wrap codex --code-memory none` است. حالت حفظ اطلاعات با `HEADROOM_LOSSLESS=1` انتخاب می‌شود؛ `HEADROOM_OUTPUT_SHAPER=0` حفظ شود. این مسیر CLI است و برای نشست فعلی Desktop فعال نشده. راه‌اندازی CLI باید در ترمینال تعاملی خود کاربر باشد.

مدل/سطح reasoning تغییر نکرد؛ ابزار یادگیری از تاریخچه اجرا نشد. هیچ اسکریپت عمومی برای کم‌کردن سقف خروجی یا دست‌کاری قواعد پروژه اضافه نشد.

## محدودیت و بازگشت

`headroom tools doctor` برای codebase-memory-mcp روی Windows فایل آماده ندارد؛ نصب آن انجام نشد. همان doctor، ast-grep را از مسیر registry پشتیبانی‌شده نشان نمی‌دهد، ولی اجرای واقعی `headroom sg --version` موفق است. نتیجهٔ doctor کلی PASS گزارش نمی‌شود.

حذف اتصال اضافه‌شده: `codex mcp remove headroom`. چون Headroom/Serena قبلاً در ابزارهای uv وجود داشتند، برای برگشت تنظیمات، آن‌ها را کورکورانه uninstall نکن. سرور موقت این بررسی متوقف شده است.
