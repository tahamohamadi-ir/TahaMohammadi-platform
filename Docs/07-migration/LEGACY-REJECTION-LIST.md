# Legacy Rejection List

Do not migrate these items into new frontend source:

- legacy `apps/web` components, layouts, and styles;
- unprocessed `@theme` CSS output;
- Tailwind utility assumptions without a verified compiler;
- generic giant SVG empty states;
- hard-coded alternate-language labels;
- invented CV dates or file formats;
- missing Pagefind build output;
- concept-screen copy;
- legacy frontend release-ready claims.

The legacy frontend may be inspected only to recover verified behavior or interface evidence.
