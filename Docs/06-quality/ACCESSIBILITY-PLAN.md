Target WCAG 2.2 AA for public and admin experiences.

Required checks:

- semantic landmarks and headings;
- keyboard navigation and visible focus;
- accessible names and error association;
- 44 by 44 CSS-pixel targets where applicable;
- color contrast in both themes;
- 200 percent zoom and responsive reflow;
- reduced motion;
- language and direction metadata;
- screen-reader status and form-error announcements.

Automated checks support manual testing. Automated checks do not certify compliance.
